# Daily discovery feed

`daily.json` is generated by `pnpm discover` (or the `Discover daily topics` GitHub Action).

- **Seed topics** (`content/topics/`) stay as easy, curated labs.
- **Daily feed** is real trending/learnable topics from HN, GitHub, arXiv, Dev.to, and optionally Firecrawl.
- The extension prefers live/remote discovery; seed is the offline backup.

## Secrets

Store `FIRECRAWL_API_KEY` in:

1. Local `.env` (gitignored) for `pnpm discover`
2. GitHub Actions secret `FIRECRAWL_API_KEY` for the cron job

Never ship the key inside the extension.
