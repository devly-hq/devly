# Requirements

Product name: **Devly**. Mascot: **Shade**.

## Functional

- Onboarding without account
- Daily 2–3 recommendations
- Topic search, save, hide, mark known, custom topic
- Agent selection with capability detection
- Three workspace modes
- Multi-stage orchestration with cancellation and resume metadata
- Execution plan approval + denylist
- Independent verification + repair (default max 3)
- Interactive lesson + Ask Shade
- Shade customization

## Non-functional

- Lazy activation; do not block IDE startup
- No telemetry without consent
- Secrets redacted from logs
- CSP on webviews
- Workspace Trust respected
- Cross-platform path/process handling (macOS, Linux, Windows)
